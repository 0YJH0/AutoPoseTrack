# 创新版算法与训练协议

## 方法边界

本版本不把 Global/Local 工程分支本身作为创新，而将研究问题定义为：从推理时
可观测的 RGB 跟踪历史预测“局部 tracker 在未来是否仍可恢复”，再结合失败与
计算成本决定是否调用昂贵的全局重定位。MegaPose 两个专家保持冻结。

## 1. 经验可恢复域

对某个带 GT pose 的 anchor frame，在物体局部坐标系右乘确定性扰动：

\[
\widetilde T_t=T_t^{GT}\Delta T(\Delta R,\Delta t).
\]

以该姿态作为 MegaPose RGB refiner 的初值，最多运行未来 10 帧。若任一输出满足

\[
ADD(-S)(\hat T_{t+k},T_{t+k}^{GT})<0.1d,
\]

则该试验标为可恢复。每个试验保存扰动、初始误差、最小未来误差、首次恢复
步数和失败原因。扰动使用显式网格与固定 trial ID，便于重复和分层统计。

最小 GPU 检查：

```bash
docker compose --profile gpu run --rm megapose \
  bash scripts/run_megapose_headless.sh \
  python -m scripts.run_recovery_basin \
  --dataset-root /data/ycbv --object-id 5 --sequence 50 \
  --anchor-stride 10 --future-frames 10 --max-trials 4 \
  --output outputs/recovery_basin_smoke
```

去掉 `--max-trials` 后运行配置中的完整扰动网格。完整实验计算量明显高于自然
rollout，应先通过小规模检查。

## 2. 因果时序可恢复性预测

默认特征生成器不再把过去帧压成一个统计量，而是构造 5 帧因果窗口。每一帧
包含 score、score 变化、运行时间、bbox 几何以及旋转/平移跳变，并附带 padding
valid mask。得到的二维训练矩阵实际表示 `[N, L*D+L]`，可以先训练透明线性
基线，后续无须更改数据协议即可替换为 MLP、TCN 或 Transformer。

标签仍由离线 GT 产生；输入矩阵不含 GT pose、pose error、visibility GT 或
depth。默认命令：

```bash
python -m scripts.build_recoverability_features \
  --rollout outputs/ycbv_object5_rollout_150/rollout.csv \
  --diameter-m 0.196463 --history-frames 5 --future-frames 10 \
  --output outputs/ycbv_object5_temporal_features
```

`--summary-features` 只用于复现旧的 9 维消融基线。

## 3. 成本敏感闭环路由

局部分支的期望风险定义为：

\[
C_{local}(p)=c_{local}+(1-p_{recover})c_{failure}.
\]

只有当该风险高于全局调用成本、恢复概率低于 lost threshold 且连续低分达到
指定帧数时才触发 GLOBAL。中间区域选择 WAIT，保留最后一次已接受位姿；高概率
选择 LOCAL。GLOBAL 之后有 cooldown，从而避免路由抖动。

默认配置位于 `configs/experiments/recoverability_routing.yaml`。闭环执行类
`RecoverabilityAwareTracker` 在提交 local candidate 之前评估它，因此被判定为
不可靠的位姿不会污染后续历史。

## 4. 必须报告的消融

- 始终 LOCAL；
- 每帧 GLOBAL；
- 固定间隔 GLOBAL；
- 原始 MegaPose score 阈值；
- pose jump 阈值；
- 当前帧误差标签；
- 未来恢复标签；
- 无计算成本路由；
- 无迟滞或无 cooldown 路由；
- 旧 9 维统计特征与 5 帧因果窗口。

正式结论必须来自独立 test scenes。当前两个场景只用于实现验证，不能用于论文
性能声明。
